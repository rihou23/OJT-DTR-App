# OJT Daily Time Record (DTR) Application

A mobile-based **On-the-Job Training (OJT) Attendance and Daily Time Record (DTR) System** developed using Kotlin and Firebase. The application helps OJT trainees record their daily attendance, monitor working hours, and manage their time logs digitally.

## Features

- **Attendance Monitoring** – Records morning and afternoon time-in and time-out.
- **Automatic Working Hours Calculation** – Calculates the total hours rendered by trainees.
- **Facial Recognition** – Uses facial recognition for identity verification.
- **Biometric Authentication** – Provides an additional layer of authentication.
- **Location Verification** – Uses GPS and geofencing to verify the trainee's location during attendance.
- **Firebase Integration** – Stores and manages attendance records using Cloud Firestore.
- **Attendance Status** – Tracks attendance records, including Present and Half-day status.

## Technologies Used

- Kotlin
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Google Maps API
- ML Kit
- Face Recognition
- GPS and Geofencing

## Project Purpose

This application was developed to simplify and improve the attendance monitoring process for OJT trainees. It aims to provide a more convenient, organized, and reliable way of recording daily attendance while reducing manual timekeeping.

## Project Status

Developed as an academic project for On-the-Job Training (OJT) attendance monitoring.
